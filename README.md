PhantomCore é uma estrutura modular para conexões SSH automatizadas e interações com dispositivos dentro de redes locais. Inspirado em ferramentas clássicas de administração remota e ofensiva, PhantomCore foi projetado para fins educacionais, automação e testes de segurança em ambientes controlados.

Funcionalidades
 Scanner de rede local com identificação de hosts ativos.
 
 Automação de conexões SSH com credenciais padrão ou fornecidas.
 
 Execução remota de comandos via SSH em dispositivos comprometidos.
 
 Registro de logs das interações e execuções.
 
 Estrutura modular pronta para expansão: adicione payloads, ferramentas ou novos protocolos.
 
 Compatível com ambientes de laboratório e testes de engenharia social (simulado).

 Aviso Legal

Este projeto é estritamente educacional.

Toda e qualquer ação envolvendo PhantomCore deve ser realizada somente em ambientes autorizados e com o consentimento explícito dos responsáveis pela rede/teste.

O uso indevido desta ferramenta pode violar leis locais de cibersegurança.

Tecnologias
Python 3

Socket & Threads (para scanner)

Paramiko (para SSH)

Estrutura pronta para integração com outros módulos (ex: fake_site, keylogger, logger remoto etc.)
